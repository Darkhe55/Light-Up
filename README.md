# 点灯 Light Up

一个基于 Web 的点灯（Light Up / Akari）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5178/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 在空地放灯泡，灯泡照亮横向和纵向直到被墙挡住
- 数字墙四邻的灯泡数必须等于数字
- 所有空地都要被照亮
- 任意两个灯泡不能互相照亮

## 逻辑解题规则

「逻辑解题」只做可证明的局部推理，反复跑到不动点，推不动就停（不靠猜、不枚举解），
每一步回放都会标出规则编号与理由：

| 规则 | 结论 |
|------|------|
| R1 | 数字墙四邻灯泡数已等于数字（含 0）→ 其余候选邻格打叉 |
| R2 | 数字墙还差 N 个、可放邻格恰好 N 个 → 这些邻格全部放灯泡 |
| R3 | 某个还没被照亮的空地，所有能照亮它的位置只剩 1 个 → 那里放灯泡 |
| R4 | 某格放灯泡会照亮数字墙的候选邻格、导致那面墙凑不够 → 该格打叉（假放反证） |
| R5 | 墙/边界围出的区域必须各自有光源；区域还没有灯泡且只剩一个可放位置 → 那里放灯泡 |

亮格与打叉格同等视为「不能放灯泡」：已照亮的格不会再放灯，灯泡之间不会互照。

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 循环：空 → 灯泡 → 叉 → 空 |
| 右键点格 | 直接标叉 / 取消 |
| 按住拖动 | 连续涂写 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移
- **自定义题板**：输入尺寸与墙/数字，保存到题库后可编辑或删除，支持唯一解校验和求解
- **规则回放**：只对未定且未被照亮的候选位下结论，不把亮格打叉

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 从图片导入题库（识图）

`scripts/import-image.mjs` 用 Playwright + Edge 全自动识别点灯题面图片（黑墙/白格/白字数字、任意矩形尺寸），
默认**只预览**，加 `--append` 才写入 `src/imported-puzzles.ts`（该文件不会被 `npm run gen` 覆盖）。

```bash
npm run import-image -- month.png                 # 预览识别结果
npm run import-image -- month.png --verify        # 预览 + 唯一解校验 + 参考解
npm run import-image -- month.png --append        # 写入题库
npm run import-image -- month.png --append --verify --name "月度 · 40×50"
```

识别流程：暗像素投影 + 多阈值扫描拟合等距网格线（自动判定行/列数）→ 四角底色区分墙/空地 →
格心自适应二值化 + 多字体模板匹配识别数字 → 用「数字出现在哪种底色上」自动判定墙色极性。

常用参数：

| 参数 | 说明 |
|------|------|
| `--width N` / `--height N` | 手动指定网格尺寸（自动判定失败时） |
| `--digits 01234` | 参与匹配的数字字符集 |
| `--invert` | 强制反转墙色极性（默认按数字所在底色自动判定） |
| `--map "x,y=字符,..."` | 人工修正某格，坐标 0 基（列,行），字符取 `.` `#` `0`-`4` |
| `--json out.json` | 导出识别结果（宽高 / 题面串 / 参考解 / 是否唯一） |
| `--verify` | 调项目 solver 检查唯一解并求参考解（超时只告警） |
| `--append` | 写入 `src/imported-puzzles.ts`（配合 `--dry` 可只演练不写） |
| `--dry` | 不写入 |
| `--timeout 秒` | 唯一性校验的时间预算（默认 25s，超时只告警） |

## 题板尺寸与形状支持

- **题面模型**：每格「空地 / 无数字墙 / 0–4 数字墙」，`width × height` 独立；
  渲染、命中、校验、回溯求解、逻辑解题都按宽高分别计算。
- **内置题库**：5×5～12×12 正方形。
- **自定义题板**：宽 3–50、高 3–60，任意非正方形；可逐格画「空地 / 无数字墙 / 数字墙」，
  因此**天然支持异形题板**：墙可以围出任意形状的可玩区域（墙格不可填、不可照亮），
  规则里的「全部空地照亮」「数字墙四邻」都按实际墙位计算。
- **识图导入**：`month.png` 识别为 **40×50（2000 格）**、700 面墙（含 250 面数字墙），
  支持 `--width/--height` 覆盖。
- **异形/外部空格**：墙即「非空格」，原规则完全适用；没有额外「棋盘外格子」概念，无需变体语义。
- **验证**：`npm run build`、`npm run check`、`npm run logic-test` 通过；内置参考解/唯一解/逻辑引擎自检通过；
  自定义 10×6 非正方形题板浏览器渲染比例正确；40×50 导入题可正常加载/渲染。
- **限制**：50×60 级自定义题可以用，但回溯求解/唯一性会超时（有预算上限）；
  40×50 导入大题的「求解/显示解」可能跑不动（题图本身可直接游玩）。
